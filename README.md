# simio

Structured C++ skeleton project for molecular frame analysis.

## Layout

- `include/simio/simio.hpp`: core header-only pipeline and data model
- `include/simio/layered_pipeline.hpp`: strict 3-layer architecture (Layer0/Layer1/Layer2)
- `include/simio/binning/FrameBinner.hpp`: center-shifted XZ bin mapping
- `include/simio/regions/ChannelRegion.hpp`: channel membership + gate side classification
- `include/simio/intrinsics/WaterDipole.hpp`: OHH dipole/com intrinsic with PBC-unwrapping
- `src/properties/DensityXZ.cpp`: XZ density kernel
- `src/properties/DipoleXZ.cpp`: XZ dipole kernel
- `src/properties/GatingCenterPlane.cpp`: center-plane crossing kernel
- `src/properties/GatingPbcWrap.cpp`: wrap-based crossing kernel
- `examples/main.cpp`: multi-frame demo (`5` water + `3` Na + `3` Cl, `4` threads)
- `examples/layered_arch_demo.cpp`: strict layered API demo with split property modules
- `tests/smoke_test.cpp`: minimal compile/runtime smoke check
- `CMakeLists.txt`: build configuration

## Build

```bash
cmake -S . -B build
cmake --build build -j
```

Optional root `Makefile` wrapper:

```bash
make build        # configure + build
make test         # build + ctest

```

## Unified One-Pass Run (All Properties)

Run one driver that reads XTC once, computes all current analysis properties, and writes ten CSV files:

```bash
./build/simio_xtc_all_properties react_neu_9_6_20.xtc 100 4 0.5 5896 110 110 7.11 12.89 0.901 1.801 100 0.35 0.38 0.35 all results 50
```

JSON config mode (same fields, defaults applied when omitted):

```bash
./build/simio_xtc_all_properties --config all_props_config.json
# or
./build/simio_xtc_all_properties all_props_config.json
```

### Generating topology summary

Generate a topology summary JSON from a GRO structure:

```bash
./bin/simio_mini_gro_topology system.gro "SOL,NA,CL" 2 1.25 setup_from_gro.json
```

Then run analysis with a config that references this file:

```bash
./bin/simio_xtc_all_properties config.json
```

Set the topology summary path in config JSON as:

```json
"topology_json": "setup_from_gro.json"
```

### Single-run notebook report

After generating CSV outputs in a run directory (example: `runs/rep_01`), render the
single-run report directly into that run folder:

```bash
./bin/simio_xtc_all_properties config.json
python scripts/render_single_run_report.py runs/rep_01
```

Generated artifacts:
- `runs/rep_01/report/figures/*.png`
- `runs/rep_01/report/summary_table.csv`
- `runs/rep_01/report/simio_single_run_report.ipynb`

When `topology_json` is set:
- `nsol/nna/ncl` are inferred from `types[].name/types[].molecules` using `water_names`, `na_names`, `cl_names`.
- all molecule blocks in `types[]` are preserved in order for atom-index mapping; names not in `water_names/na_names/cl_names` are kept as `Other` (ignored in analysis) but still contribute offsets.
- each `types[]` entry should include `atoms_per_molecule` (required to preserve offsets for unmapped species, e.g. walls).
- if `use_channel_bounds_from_topology=true`, then:
  - `xmin/xmax = channel.min[0]/channel.max[0]`
  - `zmin/zmax = channel.min[2]/channel.max[2]`
- explicit `nsol/nna/ncl/xmin/xmax/zmin/zmax` values in the same JSON override inferred values.

Arguments:
- `trajectory.xtc`
- `max_frames` (default `100`)
- `frame_begin` (default `0`, 0-based inclusive)
- `frame_end` (default `-1`, 0-based exclusive; `-1` means until EOF)
- `threads` (default `4`)
- `grid_cell_nm` (default `0.5`)
- `nsol` (default `5896`)
- `nna` (default `110`)
- `ncl` (default `110`)
- `xmin` (default `7.11`)
- `xmax` (default `12.89`)
- `zmin` (default `0.901`)
- `zmax` (default `1.801`)
- `nx` x-bins (default `100`)
- `r_cw` (default `0.35`)
- `r_aw` (default `0.38`)
- `r_oo` (default `0.35`)
- `gating_sel` in `all|now|both` (default `all`)
- `out_dir` (default `"."`)
- `jump_keep_frames` max lag rows for jump/MSD (`50` means rows `lag=1..50`)

Frame window semantics:
- processed frames satisfy `frame_begin <= frame_idx < frame_end` (if `frame_end != -1`)
- final processed count is capped by `max_frames`

Outputs:
- `<out_dir>/density_x.csv`
- `<out_dir>/density_z.csv`
- `<out_dir>/dipole_x.csv`
- `<out_dir>/dipole_z.csv`
- `<out_dir>/coord_x.csv`
- `<out_dir>/channel_count_xz.csv`
- `<out_dir>/gating_flux.csv`
- `<out_dir>/jump_msd.csv`
- `<out_dir>/msd_x_channel.csv`
- `<out_dir>/msd_z_channel.csv`
- `<out_dir>/vacf_y.csv`
- `<out_dir>/vacf_x_channel.csv`
- `<out_dir>/vacf_z_channel_raw.csv`

`<out_dir>/dipole_z.csv` columns:
- `z_center_nm`
- `mux_mean`, `mux_sem` (raw signed)
- `mux_fold_mean`, `mux_fold_sem` (x-folded around channel midpoint:
  left half uses `-mux`, right half uses `+mux`)
- `muz_mean`, `muz_sem`
- `count_mean`, `count_sem`

`<out_dir>/density_z.csv` includes ionic charge density:
- `rho_q_e_mean`, `rho_q_e_sem` with `rho_q = rho_na - rho_cl` (units: `e/nm^3`)

`<out_dir>/jump_msd.csv` columns:
- lag rows with sliding windows: `lag_frames=1..jump_keep_frames`
- lag timing and counts: `lag_time_ps_mean`, `lag_time_ps_sem`, `n_pairs`, `n_samples_all`
- lag-resolved MSD (`nm^2`) in `x/y/z/r2` for all molecules and for each species (`water`, `na`, `cl`)
- `msd_z_*` uses unwrapped continuous trajectories; `msd_z_raw_*` uses per-frame raw box z (no time unwrapping)
- lag-resolved max jump in x (`nm`, min-image `|dx|`) for all molecules and each species (`water`, `na`, `cl`)

`<out_dir>/msd_x_channel.csv` columns:
- lag rows with channel survival condition (`lag_frames=1..jump_keep_frames`)
- `lag_ps`
- per-species channel-survival `MSD_x` means (`water`, `na`, `cl`)
- per-species sample counts (`n_samples_water`, `n_samples_na`, `n_samples_cl`)

`<out_dir>/msd_z_channel.csv` columns:
- lag rows with the same channel survival condition as `msd_x_channel`
- `lag_ps`
- per-species channel-survival `MSD_z` from unwrapped coordinates: `msd_z_channel_unwrapped_*`
- per-species channel-survival `MSD_z` from raw z coordinates: `msd_z_channel_raw_*`
- per-species sample counts (`n_samples_water`, `n_samples_na`, `n_samples_cl`)
- lag-1 seam diagnostic per species: `max_abs_dz_lag1_*` (`max |z(t)-z(t-1)|` over included pairs)

`<out_dir>/vacf_y.csv` columns:
- lag rows (`lag_frames=0..jump_keep_frames`)
- `lag_ps`
- per-species `vacf_y` from continuous y velocities (`nm^2/ps^2`)
- per-species cumulative trapezoidal `D_y_from_vacf` (`nm^2/ps`)
- per-species sample counts (`n_samples_water`, `n_samples_na`, `n_samples_cl`)
- plateau diagnostic is also printed to stdout as mean of the last 10 `D_y_from_vacf` values

`<out_dir>/vacf_x_channel.csv` columns:
- lag rows (`lag_frames=0..jump_keep_frames`)
- `lag_ps`
- per-species channel-survival `vacf_x_channel` from raw-x velocities (`nm^2/ps^2`)
- per-species cumulative trapezoidal integral `I_x_from_vacf_channel` (`nm^2/ps`)
- per-species sample counts (`n_samples_water`, `n_samples_na`, `n_samples_cl`)
- plateau diagnostic is printed to stdout as mean of the last 10 `I_x_from_vacf_channel` values

`<out_dir>/vacf_z_channel_raw.csv` columns:
- lag rows (`lag_frames=0..jump_keep_frames`)
- `lag_ps`
- per-species channel-survival `vacf_z_channel_raw` (`nm^2/ps^2`)
- per-species cumulative trapezoidal integral `I_z_from_vacf_channel_raw` (`nm^2/ps`)
- per-species sample counts (`n_samples_water`, `n_samples_na`, `n_samples_cl`)
- plateau diagnostic is printed to stdout as mean of the last 10 `I_z_from_vacf_channel_raw` values

Note:
- In `simio_xtc_all_properties`, density/dipole/coordination/HB/gating use full `x` (`[0,Lx)`). CLI `xmin/xmax` are used for channel-survival files (`<out_dir>/msd_x_channel.csv`, `<out_dir>/msd_z_channel.csv`, `<out_dir>/vacf_x_channel.csv`, `<out_dir>/vacf_z_channel_raw.csv`).
- JSON backward compatibility: `out_prefix` is still accepted as an alias for `out_dir`.

## Run example

```bash
./build/simio_example
```

Run strict layered architecture demo:

```bash
./build/simio_layered_demo
```

Layered API structure (`simio::layered`):
- Layer 0: geometry/binning/region (`Layer0Geometry`, `Layer0Data`)
- Layer 1: per-molecule intrinsics (`Layer1Intrinsics`, `Layer1Data`, `Layer1State`)
- Layer 2: property kernels (`PropertyKernel` with `requires()`, `compute_frame()`, `finalize()`)

Layer 0 uses center-aware periodic binning:
- equal bin sizes: `dx=Lx/Nx`, `dz=Lz/Nz`
- shifted indexing around configurable centers (`x_center_wrapped`, `z_center_wrapped`)
- channel classification from minimum-image relative coordinates (`channel_length_x`, `channel_height_z`)
- gate planes in center-relative z (`gate_left_rel_z`, `gate_right_rel_z`)

Split property modules:
- `DensityXZProperty` (`src/properties/DensityXZ.cpp`)
- `DipoleXZProperty` (`src/properties/DipoleXZ.cpp`)
- `GatingCenterPlaneProperty` (`src/properties/GatingCenterPlane.cpp`)
- `GatingPbcWrapProperty` (`src/properties/GatingPbcWrap.cpp`)

Gating methods:
- center-plane: minimum-image segment/plane crossing at `x = x_center`, with crossing-time `z` slab filter
- seam-plane: minimum-image segment/plane crossing at periodic seam `x = 0`, with the same crossing-time `z` slab filter

Density ROI model (`DensityXZProperty`):
- z-restricted slab (`z_min..z_max`)
- x mode: channel window (`x_min..x_max`) or full box (`0..Lx`)
- PBC-safe interval logic for wrapped/non-wrapped ranges
- number density normalization per bin: `rho = count / (dx * Ly * dz)`

The example prints a frame-by-frame log with:
- one-time topology/thread/key setup
- one-time box/grid/tls footprint line
- wrapped-range violations (`key_range_viol`, `ref_range_viol`)
- grid geometry + validation (`entries`, `dup`, `miss`, `out_of_range`, `max_bucket`, `mean_nonempty_bucket`)
- step stats (`min`, `max`, `mean`, `pbc_anom`, `pbc_cross`, `max|dr_raw_comp|`, `max|dr_min_comp|`)
- debug probes for selected molecules (`key_wrapped`, `prev_before`, `prev_after`, `dr_raw`, `dr_min_image`, `key_cont`)

Build options:
- `-DSIMIO_DEBUG=ON|OFF` enables/disables debug assertions and deep checks (default `ON`)
- `-DSIMIO_TRACE=ON|OFF` enables/disables verbose per-thread property traces (default `OFF`)

Example with trace enabled:

```bash
cmake -S . -B build -DSIMIO_TRACE=ON
cmake --build build -j
./build/simio_example
```

## Real XTC Pipeline Run

Run pipeline directly on a real XTC with SOL/Na/Cl contiguous ordering:

```bash
./build/simio_xtc_pipeline react_neu_9_6_20.xtc 3 4 0.5 5896 110 110
```

Arguments:
- `trajectory.xtc`
- `max_frames` (default `10`)
- `threads` (default `4`)
- `grid_cell_nm` (default `0.5`)
- `nsol` (default `5896`)
- `nna` (default `110`)
- `ncl` (default `110`)
- `inject_mol_id` (optional, default `-1` disabled)
- `inject_axis` (optional, `0|1|2`, default `0`)
- `inject_fracL` (optional, default `0.8`)
- `inject_frame` (optional, default `1`)

Per-frame output includes:
- `pbc_cross` and `max_corr` (`|dr_raw - dr_min_image|` diagnostics)
- `step_mi(min/max/mean)` for minimum-image displacement norms
- `grid_stats` (`nonempty`, `max_bucket`, `mean_nonempty`)

Example forcing a boundary-cross event for one molecule:

```bash
./build/simio_xtc_pipeline react_neu_9_6_20.xtc 3 4 0.5 5896 110 110 0 0 0.6 1
```

## XTC Dipole Order Profile Run

Compute water dipole order profile in channel ROI and write mean+SEM CSV:

```bash
./build/simio_xtc_dipole_x react_neu_9_6_20.xtc 100 4 0.5 5896 110 110 7.11 12.89 0.901 1.801 100 dipole_x_mean.csv
```

For whole x `[0,Lx)` with the same z-slab, pass `xmin==xmax` (example `0 0`):

```bash
./build/simio_xtc_dipole_x react_neu_9_6_20.xtc 100 4 0.5 5896 110 110 0 0 0.901 1.801 100 dipole_x_mean.csv
```

Definition used per water molecule:
- select only if COM is inside ROI: `x in [xmin,xmax)`, `z in [zmin,zmax)` (PBC-safe interval handling)
- dipole direction from OHH geometry: `mu ~ (H1-O) + (H2-O)` with H atoms unwrapped around O
- normalize `mu_hat = mu / |mu|`
- folded z-order: `mu_z_fold = sign(z - z_center) * mu_hat_z`
- x-order: `mu_x = mu_hat_x`

Output CSV columns:
- `x_center_nm`
- `muz_mean`, `muz_sem`
- `muz_fold_mean`, `muz_fold_sem`
- `mux_mean`, `mux_sem`
- `count_mean`, `count_sem`

Per-frame terminal checks:
- `selected_water`
- `binned_water` (must match selected)
- `oob` (must be `0`)

## XTC Coordination Profile Run

Compute x-binned neighbor counts inside channel ROI:

```bash
./build/simio_xtc_coord_x react_neu_9_6_20.xtc 100 4 0.5 5896 110 110 7.11 12.89 0.901 1.801 100 0.35 0.38 0.35 coord_x_mean.csv
```

Definitions (distance uses minimum image, water reference atom is O):
- `IBC`: cations around central water within `r_cw`
- `IBA`: anions around central water within `r_aw`
- `BNC`: waters around central cation within `r_cw`
- `BNA`: waters around central anion within `r_aw`

Output CSV columns:
- `x_center_nm`
- `IBC_mean`, `IBC_sem`
- `IBA_mean`, `IBA_sem`
- `BNC_mean`, `BNC_sem`
- `BNA_mean`, `BNA_sem`

Per-frame terminal checks:
- `selected(w/na/cl)`
- `binned(w/na/cl)` (must match selected)
- `oob` (must be `0`)
